# Casos de Uso

A Etapa 4 foi reorganizada para evitar um único arquivo Markdown excessivamente grande. Cada caso de uso possui agora um arquivo próprio em `casos/`.

## Estrutura

- `contexto-e-atores.md`: objetivo, conceitos, atores, catálogo e regras gerais provenientes da especificação original.
- `catalogo.csv`: índice dos casos de uso.
- `casos/`: especificação individual de cada UC.
- `rastreabilidade-e-referencias-originais.md`: matriz e referências presentes no documento consolidado original.

## Status de consolidação

**Baseline funcional reconciliada.**

O catálogo vigente preserva RF-001 a RF-023 e a V1 possui 19 requisitos funcionais ativos. RF-012 a RF-014 e RF-019 são futuros/inativos. Entre os Casos de Uso, UC-013 (Transferências), UC-018 (PIN) e UC-022 (Patrimônio Total) permanecem futuros/inativos; UC-023 e UC-024 representam Reset do perfil e Exclusão da conta de acesso. A proveniência histórica permanece registrada em `docs/governanca/proveniencia.csv` e no relatório de consolidação.
