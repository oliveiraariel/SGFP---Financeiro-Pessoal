## UC-019 — Gerenciar tema da aplicação

**Objetivo**

Permitir que o usuário escolha a apresentação visual da aplicação.

**Ator principal**

Usuário.

**Pré-condições**

O usuário deverá estar autenticado.

**Gatilho**

O usuário acessa a configuração de tema.

**Fluxo principal**

1. O sistema apresenta as opções disponíveis.
2. O usuário seleciona o tema.
3. O sistema aplica a seleção.
4. O sistema mantém a preferência conforme o comportamento de configuração definido.

**Fluxos alternativos**

* Na Versão 1 estarão disponíveis os temas Claro e Escuro.

**Pós-condições**

A aplicação será apresentada conforme o tema selecionado.

**Requisitos relacionados**

RF-020.

**Regras de negócio relacionadas**

Regras do módulo Configurações.
