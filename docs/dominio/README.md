# Etapa 5 — Mapa do Domínio

**Status:** concluída e revisada para a baseline V1 simplificada em 14/09/2026.

O Mapa do Domínio vigente está em:

- [01-mapa-de-dominio.md](01-mapa-de-dominio.md)

Ele organiza os conceitos centrais da V1 e atualmente estabelece, entre outros pontos:

- Usuário como proprietário dos dados;
- exatamente uma Conta Financeira por usuário;
- Compromisso Financeiro como previsão/obrigação;
- Lançamento Financeiro como efeito realizado;
- saldo derivado dos Lançamentos ativos;
- Categoria opcional no Compromisso;
- Transferência e Patrimônio Total fora do domínio ativo da V1;
- backup/restauração, reset e exclusão como comportamentos/mecanismos de apoio, não entidades financeiras automáticas.

Em caso de conflito com artefatos históricos anteriores a 14/09/2026, o Mapa do Domínio vigente e a baseline de governança prevalecem.
