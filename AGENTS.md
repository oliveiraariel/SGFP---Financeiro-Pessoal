# SGFP — Instruções para Agentes

Antes de qualquer tarefa neste repositório:

1. Leia `ORCHESTRATOR.md`.
2. Leia `project-manifest.yaml`.
3. Consulte somente os documentos necessários em `docs/`.
4. Respeite os gates definidos no projeto.
5. Não resolva silenciosamente conflitos de negócio.
6. Não antecipe arquitetura ou implementação.
7. Preserve identificadores e rastreabilidade.
8. Não altere regras de negócio sem base documental ou decisão humana.
9. Para alterações relevantes, utilize branch ou worktree isolada.
10. Antes de concluir, valide consistência documental e Git.

As regras operacionais completas deste projeto estão em `ORCHESTRATOR.md`.
